01Fundamentos de confianza

Confidencialidad: TLS cifra los datos en tránsito. Integridad: los hashes ayudan a detectar cambios. Autenticación: el certificado X.509 vincula una clave pública con una identidad, según la cadena de confianza.

02Identidad y certificados

Los certificados sirven para acreditar a una entidad o servicio. En esta demo no se exige una firma digital; se valida de forma local que el archivo sea un PDF correcto y que el tamaño esté dentro del límite permitido.

03Despliegue de HTTPS

En un servidor real, configura un certificado válido para tu dominio, la cadena completa de la CA y el listener TLS del puerto 443 (por ejemplo, Apache con mod_ssl o Nginx con ssl_certificate). Redirige HTTP a HTTPS y renueva el certificado antes de su vencimiento. El indicador de arriba informa el protocolo de esta página; no inspecciona el certificado ni sustituye la validación del navegador.

04Procesado local de archivos

Usa la pestaña Validar PDF para comprobar que el archivo es un PDF válido sin exigir firma digital ni certificados de confianza. La comprobación se realiza en el servidor local y acepta el documento si tiene cabecera PDF correcta y un tamaño razonable.

05Evaluación

  • Transporte: abre el sitio publicado con https:// y revisa el certificado en el navegador.
  • Formato: valida un PDF real y luego prueba un archivo con extensión .pdf pero cabecera distinta.
  • Protección: mantén el servidor local en el equipo y evita subir documentos sensibles fuera de este entorno.
  • Escala: si luego quieres firmar digitalmente, habrá que añadir validación criptográfica y cadenas de confianza de CA.

La comprobación del PDF se hace en el servidor local de esta aplicación. No se exige firma digital ni validación de certificados.

Validar un PDF sin firma digital

La validación local comprueba que el archivo tiene formato PDF correcto y un tamaño permitido; no exige firma digital ni certificados.

Resultado de validación

La comprobación se realiza en el servidor local y acepta archivos PDF con cabecera válida y tamaño correcto. No se consulta firma digital ni certificados ni se envía el archivo a servicios externos.

Codifica o decodifica texto

Codificar no cifra ni protege el texto: Base64, URL, hexadecimal y binario se pueden revertir sin contraseña.

Calcula la huella digital del texto

Un hash es irreversible: sirve para comparar integridad, pero no para recuperar el texto original. Para contraseñas de usuarios se debe usar un algoritmo específico como Argon2id, bcrypt o scrypt.

Cifra o descifra con una contraseña

El cifrado usa AES-256-GCM y una clave derivada con PBKDF2-SHA-256. El procesamiento ocurre en tu navegador; el paquete incluye los datos necesarios para descifrarlo. Guarda tu contraseña: no se puede recuperar si la pierdes.

Los archivos y textos se procesan localmente en este equipo; no se envían a servicios externos.
